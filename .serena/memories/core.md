# Aurora — Core

Self-hosted медиасервер (фильмы + сериалы): Rust/Axum бэкенд + Svelte 5 SPA. Документация и комментарии в коде — на русском.

Стек и версии: `mem:tech_stack`. Команды запуска/сборки: `mem:suggested_commands`. Что прогнать перед сдачей задачи: `mem:task_completion`. Стиль кода и паттерны (общие + Rust + Svelte): `mem:conventions`.

Бэкенд подробно (модули `src/`, стриминг, ffmpeg, тесты формы источника): `mem:backend/core`.
Фронтенд подробно (роутер, дизайн-система, TV/webOS): `mem:frontend/core`.

## Инварианты проекта

- `CLAUDE.md` в корне — обязателен к соблюдению, дублирует и уточняет часть этих заметок.
- `docs/decisions/NNNN-*.md` — дорого доставшиеся решения. Читать **до** правок ffmpeg-рецептов, HLS-нарезки и слоёв стилей. Записи не переписываются: изменилось решение — новая запись со ссылкой на старую.
- Изменение схемы БД = новый файл в `migrations/`, а не правка существующего (миграции применяются на старте).
- Прод отдаёт `frontend/dist`, вшитый в бинарь (rust-embed); после правок фронта нужна пересборка фронта.
- В репозитории есть `graphify-out/` — сгенерированный граф знаний, не трогать руками.
