# Стриминг, ffmpeg, тесты формы источника

Перед правками рецептов ffmpeg и нарезки HLS читать `docs/decisions/0001`, `0002`, `0003`, `0005`.

## Порт ffmpeg
`ffmpeg.rs` — **единственное** место, где называются бинарники `ffmpeg`/`ffprobe` и их флаги. Каждая задача — структура с `to_args()`; порядок флагов значим и зафиксирован unit-тестами. Никогда не собирать список аргументов ffmpeg где-либо ещё.

## Эндпоинты
- `/api/media/:id/stream` — прямая отдача файла с HTTP Range, не более `MAX_CHUNK_SIZE` (10 МБ) за запрос. `:id` — либо media item, либо эпизод.
- `/api/media/:id/stream-transcoded` — если аудиокодек не проигрывается браузером (`ac3`/`dts`/`truehd`/`eac3`), перекод через ffmpeg кусками ~120 с; позиция — из query `start` (секунды) или из байтового Range, пересчитанного в секунды. Иначе делегирует обычному `stream_handler`.
  - **Нельзя обрезать перекодированный поток по байтам** — ломается контейнер MP4; длительность ограничивается только `-t` у ffmpeg.
- `stream*` намеренно публичные (токен принимается query-параметром, но не проверяется) — иначе `<video>` не загрузит. Прогресс (`/api/media/:id/progress`) требует валидного JWT.

## Модули
- `transcoder.rs` — `AudioTranscoder` стримит fragmented MP4 (`-c:v copy`, аудио → AAC stereo) как async body stream; `HlsManager` генерирует HLS-сегменты лениво.
- `segments.rs` — `SegmentMap` = `Keyframes | Grid`. `Grid` валидна только при переэнкоде видео; резак copy-профиля принимает границы только типа `Keyframes` — рассинхрон-комбинация просто не компилируется.
- Чересстрочный источник не может идти через `-c:v copy` — только перекод с деинтерлейсом (решение 0005).

## Тесты
- `testkit.rs` (`#[cfg(test)]`) — оси, по которым реальные файлы различаются (`TimestampForm`, `GopForm`, `VideoForm`, `AudioForm`), `Shape::matrix()` генерит фикстуры на лету, `assert_playable` — единый чек-лист проигрываемости для всех стриминговых тестов.
- **Никогда не писать тест на самодельную фикстуру — добавлять `Shape`.** Фикстура здоровее реального релиза — причина трёх пропущенных багов.
- `cargo test` включает `every_source_shape_produces_playable_segments` (вся матрица, ~10 с, нужен ffmpeg).
- `cargo test real_library_conformance -- --ignored` — тот же чек-лист на одном реальном файле из каждой группы `(video_codec, audio_codec, pix_fmt)` в `data/aurora.db`. Его задача — найти форму источника, которой нет в матрице; нашёл — сначала добавить ось в `Shape::matrix()`, только потом чинить.
