# Конвенции

## Общее
- Язык: комментарии в коде, документация (`README.md`, `ROADMAP.md`, `METRICS.md`, `docs/`) и сообщения коммитов — **русские**. Идентификаторы — английские.
- Коммиты: `(feat|fix|refactor|chore): краткое сообщение`, без тела-списка, без co-author.
- Комментарий пишется только про неочевидное решение; очевидное не комментируется.
- Не добавлять обработку ошибок / логирование / тесты сверх того, что просили.

## Rust
- Плоская структура `src/*.rs` без слоёв hex-архитектуры — новый функционал кладётся в существующий тематический модуль, а не в новый пакет.
- `anyhow` в прикладном коде, ошибки как значения, без panic в библиотечной части.
- Общее состояние — `AppState { config, db, metrics }`, Arc-клонируется в хендлеры axum.
- Все вызовы `ffmpeg`/`ffprobe` — только через `ffmpeg.rs` (порт), см. `mem:backend/streaming`.
- Типы-инварианты предпочтительнее проверок в рантайме: недопустимая комбинация должна не компилироваться (пример — `SegmentMap::Keyframes | Grid` в `segments.rs`).
- Тесты — в тех же файлах под `#[cfg(test)]`; фикстуры только через `testkit.rs`.

## Svelte / TS
- Только Svelte 5 runes; состояние — rune-сторы в `src/lib/*.svelte.ts` (`auth.svelte.ts`), не контексты.
- Параметры маршрута передаются компонентам как пропсы (`<MovieDetail id={route.params.id} />`), не читаются из хука.
- Логика — в сторах/`lib`, компоненты маленькие.
- Стили: без utility-классов в разметке, без `px` (rem, корневой font-size масштабирует UI). Слои и правила — `mem:frontend/design_system`.
