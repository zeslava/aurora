# Завершение задачи

## Бэкенд (Rust)
1. `cargo fmt`
2. `cargo clippy` — без предупреждений
3. `cargo test` (нужен ffmpeg/ffprobe в PATH; включает матрицу форм источника)

Или разом: `task lint && task test`.

При правках стриминга/ffmpeg дополнительно: `cargo test real_library_conformance -- --ignored` (реальная библиотека из `data/aurora.db`).

## Фронтенд
`cd frontend && npm run build` — это и есть проверка: внутри `svelte-check` + `stylelint` + сборка в `frontend/dist`. Прод отдаёт именно `dist`, поэтому сборка обязательна после любых правок фронта.

## Полная сборка
`task build` (фронт + релизный бинарь).

Тесты добавлять только если попросили (глобальное правило пользователя), но существующие обязаны оставаться зелёными.
