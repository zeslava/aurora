Формат: одна запись — одно решение. Контекст (что не работало), решение, следствия, и главное —
**что сломается, если сделать «очевидным» способом**. Без этой последней части запись
бесполезна: именно она удерживает от отката.

Записи не переписываются задним числом. Если решение изменилось — новая запись со ссылкой
на старую.
