# Дизайн-система Aurora

Один тёмный кинематографический интерфейс, который читается и с двух метров от дивана, и
с ноутбука. Всё, что рисуется на экране, собирается из токенов, общих классов и компонентов
ниже. Новый цвет, отступ или размер шрифта — это изменение системы, а не файла.

Где что лежит:

| Слой | Файл | Что в нём |
| --- | --- | --- |
| Токены | `frontend/src/tokens.css` | единственное место, где допустимы сырые цвета и размеры |
| База и общие классы | `frontend/src/index.css` | сброс, масштаб, фокус, `.btn`, `.input`, `.hero`, … |
| Компоненты | `frontend/src/components/` | всё, что переиспользуется в разметке |
| Локальная раскладка | `<style>` в `.svelte` | стили, у которых один потребитель |

## Токены

Три слоя, брать всегда из самого верхнего.

**1. Палитра** (`--gray-700`, `--sky-500`, `--red-400`, …) — сырые значения. В компонентах
не использовать: она отвечает на вопрос «какой это цвет», а не «зачем он здесь».

**2. Семантика** — то, что берёт разметка.

| Группа | Токены | Назначение |
| --- | --- | --- |
| Поверхности | `--bg`, `--surface`, `--surface-2`, `--surface-3`, `--border` | фон приложения и карточек, чем выше номер — тем «ближе» слой |
| Текст | `--text`, `--text-muted`, `--text-dim` | основной, второстепенный, служебный |
| Кадр | `--bg-cinema`, `--text-on-media`, `--surface-glass`, `--blur-glass` | всё, что лежит поверх видео или постера |
| Акцент | `--accent`, `--accent-strong`, `--accent-strong-hover` | прогресс и главное действие |
| Статусы | `--success`, `--danger`, `--warning` + `*-bg`, `*-border`, `*-text` | сообщения и бейджи |
| Затемнения | `--scrim-haze` → `--scrim-subtle` → `--scrim-veil` → `--scrim` → `--scrim-media` → `--scrim-strong` → `--overlay` → `--overlay-strong` | шкала от почти прозрачного к почти непрозрачному |
| Отступы | `--space-1`…`--space-20` | шкала; промежуточных значений нет |
| Скругления | `--radius-sm`, `--radius`, `--radius-lg`, `--radius-full` | |
| Типографика | `--text-xs`…`--text-7xl`, `--weight-medium`…`--weight-extrabold`, `--font`, `--font-mono` | |
| Глубина | `--z-behind`, `--z-base`, `--z-raised`, `--z-overlay`, `--z-modal` | голых чисел в `z-index` быть не должно |
| Движение | `--transition`, `--transition-slow`, `--ease` | |
| Прочее | `--shadow-lg`, `--shadow-xl`, `--shadow-text`, `--focus-ring`, `--container` | |

**3. Локальные переменные компонента** — когда значение вычисляется и токеном не выражается
(`--ph-hue` в `PosterPlaceholder`, `--played` в шкале плеера). Объявляются в самом компоненте.

Нужен новый оттенок или размер? Сначала проверьте, что подходящей ступени нет. Если нет —
добавляйте ступень в `tokens.css` с комментарием зачем, а не значение в компонент.

## Масштаб и брейкпоинты

Корневой `font-size` — единственный рычаг общего масштаба: все токены заданы в `rem`, поэтому
`html { font-size }` тянет весь интерфейс разом. Он растёт на больших экранах (1600px → 18px,
1900px → 20px) и равен 22px в ТВ-режиме (`html[data-tv]`, выставляет `initTvMode()`).

Отсюда правило: **никаких размеров в `px`** — ни шрифтов, ни отступов. Единственные
исключения — сам масштаб в `index.css` и толщина линий (границы, полоса прогресса).

Разрешённые брейкпоинты — 639, 640, 768, 1024, 1280, 1600, 1900. Другие значения не пройдут
линтер: разнобой в брейкпоинтах ломает сетку сильнее, чем неудобство от округления.

Синтаксис медиа-запросов — только `min-width`/`max-width`, без range-нотации (`width >= …`):
её не понимает браузер webOS.

## Фокус, ТВ и Magic Remote

Приложение живёт в трёх режимах ввода, и это часть системы, а не деталь реализации:

- **мышь/тач** — работают `:hover` и клик;
- **D-pad на пульте** — `:focus-visible` рисует обводку `--focus-ring`; на webOS 2020− есть
  фолбэк на `:focus` через `@supports not selector(:focus-visible)`;
- **Magic Remote (курсор)** — `html[data-input-mode='pointer']` гасит обводку: её роль играет
  сам курсор.

Следствия, о которых легко забыть:

- `--focus-ring` означает **только фокус**. Состояние контента («продолжить с этой серии»)
  красится в `--accent` через `.marker-resume` — иначе оно исчезает в курсорном режиме
  вместе с обводкой.
- Фокус может стоять на кнопке внутри строки — подсвечивать нужно строку целиком
  (`:has(:focus-visible)` + фолбэк `:focus-within`), иначе с дивана обводку не видно.
- Всё кликабельное должно быть достижимо с пульта: `tabindex` и обработка Enter/Space.

Анимации гасятся при `prefers-reduced-motion: reduce` — глобально, в `index.css`.

`.screen-message` (+ `--dark`), `.detail-bg`, `.hero` (+ `--compact`, `.hero__content`,
`.hero__title`, `.hero__meta`, `.hero__actions`), `.auth-screen`/`.auth-card`/`.auth-form`/… .

`.input`, `.select`, `.alert`, `.text-error`, `.text-success`, `.badge` (+ `--success`),
`.progress` (+ `--thin`, `--overlay`, `.progress__bar`), `.media-grid`, `.poster`,

## Правила

1. **Только `var(--*)`.** Цвета, отступы, скругления, размеры и веса шрифта, `z-index`,
   длительности — из токенов. Сырое значение допустимо в `tokens.css` и нигде больше.
2. **Никаких utility-классов в разметке.** Не `class="mt-4 flex"`, а осмысленное имя блока.
3. **Класс переезжает в `index.css`, когда у него появляется третий потребитель.** До этого
   живёт в `<style>` компонента. Копипаста между двумя экранами — сигнал вынести не класс,
   а компонент.
4. **Имена — BEM-подобные:** `.block`, `.block__element`, `.block--modifier`.
5. **Комментарий обязателен там, где решение неочевидно** (обход бага браузера, компенсация
   раскладки). Комментарии — по-русски, как и везде в коде.
6. **Исключение из линтера — через `/* stylelint-disable-next-line … -- причина */`**, а не
   ослаблением правила в конфиге.

Проверка: `npm run lint:css` (входит в `npm run build`). Конфиг — `frontend/.stylelintrc.json`.

## Чек-лист ревью

- [ ] Нет ни одного сырого цвета, `px`-отступа или числа в `z-index` вне `tokens.css`
- [ ] Не появился класс, дублирующий существующий общий или компонент
- [ ] Новый интерактивный элемент достижим с пульта и его фокус видно с двух метров
- [ ] Проверено в ТВ-режиме (`document.documentElement.dataset.tv = ''`) и в курсорном
      (`data-input-mode='pointer'`)
- [ ] `npm run lint:css` и `npm run build` проходят

Решения, стоившие крови, — в [`docs/decisions/`](decisions/README.md), в частности
[0004 — Слои дизайн-системы](decisions/0004-design-system-layers.md).
