## 🗄️ **Фаза 2: База данных и модели (1-2 недели)** ✅ **ВЫПОЛНЕНО**

### **2.1 Схема данных (упрощенная)** ✅
```sql
-- Пользователи (пока один админ)
CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    username TEXT UNIQUE,
    password_hash TEXT
);

-- Библиотеки (пути к медиа)
CREATE TABLE libraries (
    id INTEGER PRIMARY KEY,
    name TEXT,
    path TEXT UNIQUE,
    type TEXT -- 'movie' или 'tv'
);

-- Медиа элементы
CREATE TABLE media_items (
    id INTEGER PRIMARY KEY,
    library_id INTEGER,
    title TEXT,
    year INTEGER,
    file_path TEXT UNIQUE,
    duration INTEGER, -- в секундах
    video_codec TEXT,
    resolution TEXT,
    created_at TIMESTAMP
);

-- Серии (для сериалов)
CREATE TABLE episodes (
    id INTEGER PRIMARY KEY,
    series_id INTEGER,
    season_number INTEGER,
    episode_number INTEGER,
    title TEXT,
    file_path TEXT,
    FOREIGN KEY(series_id) REFERENCES media_items(id)
);

-- Прогресс просмотра
CREATE TABLE playback_state (
    user_id INTEGER,
    media_id INTEGER,
    position INTEGER, -- секунда остановки
    completed BOOLEAN,
    last_watched TIMESTAMP,
    PRIMARY KEY(user_id, media_id)
);
```

## 📺 **webOS-приложение (LG TV)**

Aurora упаковывается в нативное webOS-приложение (`.ipk`): статичный SPA,
который обращается к серверу Aurora по HTTP. Файлы приложения — в
`frontend/webos/` (`appinfo.json`, `icon.png` 80×80, `largeIcon.png` 130×130),
версия берётся из `frontend/package.json`.

**Адрес сервера.** По умолчанию вводится в самом приложении при первом запуске
(экран «Укажите адрес сервера», хранится в `localStorage`) — один `.ipk`
работает с любым сервером. Опционально адрес можно зашить в билд (`VITE_API_URL`),
тогда экран ввода не показывается. `index.html` в упакованном приложении грузится
по `file://`, поэтому ассеты собираются с относительной базой (`VITE_BASE=./`).

### Сборка `.ipk`

Требования: `ares-cli` (`npm i -g @webosose/ares-cli`).

```bash
scripts/build-webos.sh                       # адрес сервера вводится в приложении
scripts/build-webos.sh http://192.168.1.10:4000   # либо зашить в билд
# результат: build/ipk/com.aurora.mediaserver_<version>_all.ipk
```

### Публикация на ТВ (sideload через Developer Mode)

Для self-hosted проекта это основной путь (публикация в LG Content Store не
нужна: приложение указывает на пользовательский сервер). Аналог homebrew-раздачи
Jellyfin — раздаём `.ipk` + инструкцию.

Разово на ТВ:
1. Установить приложение **Developer Mode** из LG Content Store, войти аккаунтом
   с [developer.lge.com](https://developer.lge.com).
2. Включить Dev Mode + Key Server — ТВ покажет IP и **passphrase**.

Разово на машине сборки:
```bash
ares-setup-device                          # добавить ТВ: имя, IP, порт 9922
ares-novacom --device <name> --getkey      # ввести passphrase с ТВ
```

Каждый релиз:
```bash
scripts/build-webos.sh
ares-install --device <name> build/ipk/com.aurora.mediaserver_<version>_all.ipk
ares-launch  --device <name> com.aurora.mediaserver
```

> Dev Mode-сессия живёт ~50 часов, затем приложение отключается — продлевается
> в приложении Developer Mode на ТВ.

Готовый `.ipk` удобно прикладывать к GitHub Releases как артефакт.

## 🐳 **Docker и деплой**

### **Сборка и запуск через Docker**

#### **1. Сборка образа:**
```bash
docker build -t aurora .
```

#### **2. Запуск через docker-compose:**
```bash
# Отредактируйте docker-compose.yml, указав пути к вашим медиатекам
docker-compose up -d
```

#### **3. Настройка медиатек:**
В `docker-compose.yml` укажите пути к вашим медиатекам:
```yaml
volumes:
  - /host/path/to/movies:/app/media/movies:ro
  - /host/path/to/tv:/app/media/tv:ro
```

И установите переменную окружения:
```yaml
environment:
  - MEDIA_PATHS=/app/media/movies,/app/media/tv
```

#### **4. Первый запуск:**
1. Запустите контейнер: `docker-compose up -d`
2. Откройте браузер: `http://localhost:4000`
3. Зарегистрируйте пользователя
4. Перейдите в настройки и запустите сканирование медиатеки

### **Ручная сборка (без Docker)**

#### **Сборка сервера:**
```bash
# Установите Rust и зависимости
cargo build --release

# Соберите фронтенд
cd frontend
npm install
npm run build
cd ..
```

#### **Запуск:**
```bash
# Установите переменные окружения
export PORT=4000
export DATABASE_URL=sqlite:./aurora.db
export STATIC_DIR=./frontend/dist  # опционально: читать статику с диска вместо вшитой
export MEDIA_PATHS=/path/to/movies,/path/to/tv

# Запустите сервер
./target/release/aurora
```

### **Требования для Docker:**
- Docker 20.10+
- Docker Compose 2.0+
- Доступ к медиафайлам (монтирование volumes)

---

Этот план дает работающий медиасервер за 6-8 недель. Основной функционал реализован и протестирован.
