# Aurora — бэклог

Фокус: UX и простота использования, в первую очередь на телевизоре (LG webOS).
Сделанное — в истории git и [`docs/decisions/`](docs/decisions/); здесь только открытое.
Открытые пункты ревью плеера — отдельным треком в [PLAYBACK_PLAN.md](PLAYBACK_PLAN.md).

## Простота использования

- [ ] **Zero-config старт.** Если в БД нет пользователей — API отдаёт «setup required», фронт показывает мастер (создать админа + указать пути медиатеки). Пути библиотек хранить в БД (таблица `libraries`), а не только в env. `POST /api/setup` доступен только при пустой таблице `users`
- [ ] **Авто-скан.** `notify`-watcher на путях библиотек (debounce ~2 с на всплеск событий) → инкрементальный скан изменившихся путей; плюс периодический полный скан (интервал из конфига) на существующей job-механике `/api/scan`. Кнопка «Scan» становится опциональной
- [ ] **Поиск**, с ТВ — по буквам через простую экранную клавиатуру
  - [ ] `GET /api/search?q=` — `LIKE %q%` по `title` (media_items + episodes), с лимитом
  - [ ] Экранная мини-клавиатура на ТВ, навигация D-pad, ввод по OK
- [ ] **Кадр из файла как постер-фолбэк** (`ffmpeg -ss <10%> … -frames:v 1`), когда TMDB не нашёл совпадения

## ТВ

- [ ] **Проверка на старых webOS** (2020 и раньше, Chromium ~68): целевой browserslist в Vite, полифиллы при необходимости, без свежих CSS/JS-фич
- [ ] **Удалить `/api/media/:id/stream-transcoded`** и логику «2-мин чанки + байты→секунды» (`range_start_seconds`), когда HLS-путь проверен в проде и на ТВ. Сейчас фронт ещё ссылается на него в `api/client.ts`

## Безопасность (минимум, не мешающий простоте)

- [ ] Короткоживущий (~1 ч) токен для `?token=` в stream/HLS/картинках вместо основного 7-дневного JWT: query-строки оседают в логах прокси и истории браузера
- [ ] Роли и инвайты: первый пользователь → `admin` (см. zero-config), регистрация снаружи по инвайт-токену (сейчас после первого пользователя — только из LAN или вошедшим). Поле `role` в `users`, таблица/поле инвайтов
- [ ] `stream_handler`: пустой файл (`file_size - 1` уходит в underflow) → `422`; невалидный или out-of-range `Range` → `416 Range Not Satisfiable` с `Content-Range: bytes */<size>`
- [ ] Глобальный `tokio::sync::Semaphore` в `AppState` на число ffmpeg-процессов (лимит из конфига, по умолчанию 2–3): транскодер держит permit на время сессии, при исчерпании — `503`

## Качество кода

- [ ] `#[derive(sqlx::FromRow)]` на доменных типах в `models.rs` + `query_as::<_, T>()` вместо ручного маппинга строк в `database.rs`
- [ ] `ApiError` (`thiserror`) + `impl IntoResponse`: хендлеры возвращают `Result<_, ApiError>` вместо повторяющихся `(StatusCode::INTERNAL_SERVER_ERROR, Json(json!(...)))`
- [ ] Regex в `scanner.rs` → `static … = LazyLock::new(…)` вместо компиляции на каждый файл
- [ ] Разбить `server.rs` (~3.3k строк): вынести `streaming` (stream/HLS/range) и `scan` в отдельные модули, в `server.rs` оставить роутер и общие хендлеры

## Что сознательно не делаем (простота важнее)

- Мультисерверность, федерация, плагины
- Транскодинг «на все случаи» — только то, что нужно webOS и десктопным браузерам
- Настройки качества у пользователя — сервер сам решает, нужен ли транскодинг
